## 🎯 О проекте

**TechnMart** — это современный интернет-магазин бытовой и цифровой техники (ноутбуки, смартфоны, телевизоры, умные часы и другие гаджеты), ориентированный на российский рынок. Ключевая особенность проекта — интеграция интеллектуальных функций на базе машинного обучения, которые делают процесс покупки быстрым, удобным и персонализированным.

### 🌟 Ключевые особенности
- 🤖 **Интеллектуальный чат-бот** для консультаций по товарам и заказам
- 🎯 **Персонализированные рекомендации** на основе поведения пользователя
- 🛒 **Полнофункциональный каталог** с поиском, фильтрацией и сортировкой
- 📦 **Управление заказами** с отслеживанием статуса и возвратами
- 👤 **Личный кабинет** с историей покупок и избранным

## 🏗 Архитектура

Проект построен на **модульной архитектуре** с выделенным ML-сервисом для обеспечения гибкости и масштабируемости:

### Основные компоненты:

| Компонент | Стек | Порт |
|-----------|------|------|
| Backend | ASP.NET Core 8, PostgreSQL, JWT | `http://localhost:5001` |
| Frontend | Vue 3, Vite, Vue Router | `http://localhost:5173` |
| ML-сервис | FastAPI, scikit-learn, Redis (опционально) | `http://localhost:8000` |

### 🔄 Поток данных для ML
1. **Frontend/Backend** отслеживает действия пользователя (просмотры, добавления в корзину, покупки).
2. События отправляются в очередь **Redis** (`user-events`).
3. **ML-сервис** потребляет события из очереди для обучения моделей.
4. При недоступности Redis API напрямую отправляет событие в ML-сервис по HTTP (fallback).

## 🧠 AI/ML компоненты

### 1. Рекомендательная система
| Характеристика | Значение |
|----------------|----------|
| **Задача** | Ранжирование товаров по интересу пользователя |
| **Данные** | История просмотров, добавлений в корзину, покупки, характеристики товаров |
| **Модель** | Контентная фильтрация (TF-IDF + косинусное сходство) с учетом популярности |
| **Фреймворк** | scikit-learn |

### 2. Чат-бот поддержки
| Характеристика | Значение |
|----------------|----------|
| **Задача** | Классификация намерений и генерация ответов |
| **Темы** | Заказы, возвраты, статусы, приветствие |
| **Подход** | Rule-based система с векторизацией текста (TF-IDF) |
| **Метрики** | Точность распознавания интента ≥ 85% |
| **Обработка ошибок** | Предложение связаться с оператором при низкой уверенности |
