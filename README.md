## 🎯 О проекте

**TechMart** — это современный интернет-магазин бытовой и цифровой техники (ноутбуки, смартфоны, телевизоры, умные часы и другие гаджеты), ориентированный на российский рынок. Ключевая особенность проекта — интеграция интеллектуальных функций на базе машинного обучения, которые делают процесс покупки быстрым, удобным и персонализированным.

### 🌟 Ключевые особенности
- 🤖 **Интеллектуальный чат-бот** 24/7 для консультаций по товарам и заказам
- 🎯 **Персонализированные рекомендации** на основе поведения пользователя
- 🛒 **Полнофункциональный каталог** с поиском, фильтрацией и сортировкой
- 📦 **Управление заказами** с подтверждением на email
- 👤 **Личный кабинет** с историей покупок и избранным

## 🏗 Архитектура

Проект построен на **микросервисной архитектуре** для обеспечения гибкости, масштабируемости и отказоустойчивости:
### Основные компоненты:
- **Frontend**: SPA на Vue.js
- **API Gateway**: .NET Core, маршрутизация запросов
- **Бизнес-микросервисы**: каталог, заказы, пользователи (.NET Core)
- **Брокер сообщений**: Apache Kafka для асинхронной коммуникации
- **ML-сервисы**: Python (scikit-learn, TensorFlow Lite)

## 🧠 AI/ML компоненты

### 1. Рекомендательная система
| Характеристика | Значение |
|----------------|----------|
| **Задача** | Ранжирование товаров по интересу пользователя |
| **Данные** | История просмотров, покупки, характеристики товаров |
| **Модель** | Коллаборативная фильтрация + контентные признаки |
| **Метрики** | F1-Score ≥ 0.80, CTR ≥ 8% |

### 2. Чат-бот
| Характеристика | Значение |
|----------------|----------|
| **Задача** | Классификация намерений, ответы на вопросы |
| **Темы** | Заказы, товары, возвраты, статусы |
| **Подход** | Rule-based + NLP-модель |
| **Метрики** | Точность распознавания ≥ 85% |
| **Обработка ошибок** | Предложение связаться с оператором при неуверенности |
